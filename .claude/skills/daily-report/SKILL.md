# 일일 대화 정리

디스코드 대화 하루치를 주제 단위로 묶어 요약하고 노션에 남긴다.

## 절차

1. `recent_days` 로 어느 날짜에 대화가 있는지 확인한다. 날짜를 안 주면 가장 최근 날짜.
2. `list_channels` 로 채널을 확인하고, `get_conversation(channel, date)` 로 원문을 가져온다.
   여러 채널이면 채널별로 따로 부른다.
3. 주제 단위로 묶는다. **시간이 아니라 화제로 자른다** — 같은 화제가 30분 떨어져 다시
   나오면 한 덩어리다.
4. 노션에 쓰기 전에 **초안을 사용자에게 먼저 보여주고 확인받는다.**
5. 확인되면 노션 `일일 로그` DB에 기록한다.

## 묶는 기준

- 한 주제 = "무엇을 이야기했고 어떻게 결론났는가"가 한 문단으로 써지는 단위
- 결론이 안 난 주제는 **"미결"로 명시**한다. 억지로 결론을 지어내지 않는다
- 잡담·인사·일정 조율은 주제로 세우지 않는다. 마지막에 "그 외" 한 줄로 묶는다
- 참여자 이름은 발언을 옮길 때만 쓴다. "누가 무슨 말을 했다"의 나열은 요약이 아니다

## 노션 기록

`일일 로그` DB에 날짜당 한 항목:

| 속성 | 값 |
|---|---|
| 날짜 | 대화 날짜 (KST) |
| 채널 | 채널 이름 |
| 주제 | 주제명 multi-select |
| 요약 | 주제별 문단 |
| 메시지 수 | 그날 건수 |
| 원문 링크 | 그날 첫 메시지 링크 |

**멱등하게.** 같은 날짜·채널 항목이 이미 있으면 **새로 만들지 말고 덮어쓴다.**
쓰기 전에 반드시 해당 날짜로 DB를 조회한다.

## 원문 링크

`get_conversation` 출력의 각 줄 끝 `⟨메시지ID⟩` 와 헤더의 링크 틀로 만든다:
`https://discord.com/channels/{guild_id}/{channel_id}/{메시지ID}`

## 하지 말 것

- 원문에 없는 내용을 채워 넣기. 대화가 짧으면 요약도 짧게 둔다
- 결론이 안 난 논의를 결론난 것처럼 쓰기
- 확인 없이 노션에 쓰기
