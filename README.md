# Abstraction Bot — 디스코드 대화 수집 → 요약 → 노션

봇이 대화를 모아 SQLite에 쌓고, MCP로 에이전트에 노출하고, 에이전트가 정리해서 노션에 쓴다.
**운영은 거의 다 웹 콘솔에서 한다. 각 사용자는 자기 CLI 에이전트를 연동해야 쓸 수 있다.**

## 구조

```
[디스코드] ──메시지──▶ [수집 봇] ──▶ SQLite ──▶ [MCP 서버] ──▶ [내 Claude Code] ──▶ [노션]
                          │                        ▲
                       브리지                  연동 확인 (미연동이면 거부)
                          ▼                        │
                    [세팅 콘솔]  ── 페어링 ─────────┘
              대화 · 수집 · 연결 · 리더보드
```

봇에는 LLM 호출도 노션 클라이언트도 없다. 요약 프롬프트를 고쳐도 봇을 재배포하지 않는다.

## Claude 에 붙이기 — 주소 하나

콘솔에서 커넥터 주소를 복사해 Claude Desktop 설정 > 커넥터에 붙여넣으면 끝이다.

```
https://<서버>/c/<내토큰>
```

**주소 자체가 신분증이라 로그인 창이 뜨지 않는다.** 붙여넣기 한 번으로 인증까지
끝난다. 대신 주소가 곧 비밀번호다 — 남에게 보이면 그 사람이 내 대화를 조회할 수
있으니, 새면 콘솔에서 재발급해 옛 주소를 죽인다.

> 로컬 CLI 는 `.mcp.json` 으로 이미 붙어 있다. 원격 주소는 설치 없이 쓰고 싶은
> 팀원용이다.

## 일일 결산

매일 정한 시각(KST)에 전날 대화를 정리해 결산 채널에 올린다. 콘솔 **수집** 탭에서
켠다 — 버튼을 누르면 `#일일결산` 채널을 만들고(봇에 '채널 관리' 권한이 없으면
안내한다) 자동 게시를 켠다. `지금 결산 올리기` 로 특정 날짜를 수동 실행할 수도 있다.

**API 키를 쓰지 않는다.** 결산·정리·묻기는 전부 콘솔에 연동된 CLI(`claude -p` /
`codex exec`)를 비대화로 불러서 한다 — 그 계정의 구독으로 돌아간다.
연동된 CLI 가 없으면 통계 결산으로 강등된다.

> 수집된 디스코드 메시지는 **신뢰할 수 없는 입력**이다. 그 안에 "파일을 읽어라"
> 같은 지시가 섞여 있을 수 있으므로 CLI 를 부를 때 도구를 전부 막고
> (`--disallowed-tools`) 빈 임시 디렉터리에서 돌린다 — 인젝션이 통해도 만질 게 없다.

### 원문 보존 기간

기본 **90일**. 지나면 원문을 지운다. 콘솔에서 바꾸고, `0` 이면 안 지운다.

**용량 때문이 아니라 프라이버시 때문이다.** 하루 500건이면 1년치가 55MB 라 용량은
문제가 안 된다. 남의 대화 사본을 무기한 들고 있지 않는 것이 목적이고, 봇 초대를
부탁할 때 근거가 된다.

**결산은 디스코드에 게시돼 있으므로 원문이 지워져도 정리본은 남는다.** 정리된 것만
영구히 남고 원문은 소멸한다.

### 결산 모델

콘솔에서 고른다. 기본은 **Opus 5**.

| 모델 | 프로바이더 | 월 대략 |
|---|---|---|
| **Opus 5** (기본) | Anthropic | 약 6,000원 |
| Fable 5 | Anthropic | 약 12,000원 |
| Sonnet 5 | Anthropic | 약 2,400원 |
| Haiku 4.5 | Anthropic | 약 1,200원 |
| **Codex (Terra)** `gpt-5.6-terra` | OpenAI | — |

가격은 API 로 직접 부를 때의 참고값이다. **연동한 CLI 로 도니 별도 과금이 없다** —
그 계정의 구독을 쓴다. 고른 모델의 제공자에 맞는 CLI(claude / codex)를 자동으로 고른다.

**연동된 CLI 가 없으면 통계 결산**(건수·참여자·활발한 시간)으로 자동 강등된다.
없는 모델 ID 는 저장 단계에서 막는다 — 안 그러면 결산 시각에 조용히 실패한다.

## 배포

무료로 24시간 돌리는 법은 [DEPLOY.md](DEPLOY.md) 에 있다 —
**DisHost(봇 호스팅) + Cloudflare Tunnel** 조합이다.

실측 **95MB / 패키지 57MB** 라 128MB 짜리 무료 티어에 여유 있게 들어간다.
그러려고 LLM 은 공식 SDK(42MB) 대신 stdlib `urllib` 로 부른다 — 하루 한 번
HTTP POST 한 방에 SDK 두 개를 지고 갈 이유가 없다.

## 두 가지 모드

봇과 DB 는 **한 곳에서만** 돈다. 콘솔은 각자 PC 에서 뜬다.

| | `SERVER_URL` | 하는 일 |
|---|---|---|
| **서버 모드** | 비움 (기본) | 봇 + DB + API + 콘솔. 한 명만 |
| **클라이언트 모드** | 봇이 도는 주소 | 콘솔만. 조회는 서버로 넘긴다 |

클라이언트 모드에서도 **에이전트 CLI 는 각자 PC 에서 돈다** — 자격증명은 여전히
자기 PC 를 안 떠난다. 서버가 갖는 건 대화 로그와 연동 토큰뿐이다.

주소는 `SERVER_URL` 환경변수 또는 `data/config.json` 의 `server_url` 로 준다.

```json
{ "server_url": "https://내서버주소" }
```

**인증:** 페어링에 성공하면 서버가 클라이언트 토큰을 발급해 `data/session.json` 에
남긴다. 이후 원격 요청은 이 토큰으로 신분을 증명한다. 루프백(자기 PC)에서 온
요청은 토큰 없이 통과한다.

> **터널이나 호스팅 뒤에 둘 때는 `PUBLIC_SERVER=1` 을 켠다.** cloudflared 같은
> 프록시는 요청을 `127.0.0.1` 로 전달하므로, 루프백 예외를 켜둔 채 공개하면
> 주소만 아는 사람이 전부 무토큰으로 통과한다. `X-Forwarded-For` 류 헤더가
> 붙어 오면 자동으로도 막지만, 공개 배포에서는 플래그로 명시하는 게 맞다.

## 설치 · 실행

```bash
uv sync
```

`.env` 를 만든다 (`.env.example` 복사 후 `DISCORD_TOKEN` 채우기). `.env` 는 커밋되지 않는다.

**`start.bat` 더블클릭.** 창 하나에서 수집 봇과 세팅 콘솔이 같이 뜨고,
**그 창을 닫으면 둘 다 종료된다.**

> `MESSAGE CONTENT INTENT` 가 꺼지면 봇이 뜨지 않고 안내 메시지를 낸다.
> 개발자 포털 > Bot > Privileged Gateway Intents 에서 켠다.

## 세팅 콘솔 — 여기서 거의 다 한다

디스코드에서 **`/시작`** 을 치면 본인 전용 콘솔 링크가 온다 (연동 코드 자동 첨부).

| 탭 | 하는 일 |
|---|---|
| **묻기** | 채팅으로 질문·지시. 고른 채널·기간의 대화를 자료로 물려주고 답한다. 자료에 없으면 없다고 말하고, 인용에 ⟨메시지ID⟩ 를 남긴다 |
| **대화** | 채팅형 뷰어. 채널·날짜 범위 선택, 빠른 칩(오늘/어제/7일/30일), 본문 검색(하이라이트), 각 메시지에서 디스코드 원문으로 점프, **정리** 버튼으로 그 기간 요약 |
| **수집** | 서버의 채널을 켜고 끄기, 과거 대화 가져오기(날짜 범위 또는 최근 N일, 진행률 표시), 내 수집 거부 — *서버 관리 권한자만 보인다* |
| **연결** | 에이전트 계정 · 디스코드 연동 · MCP |
| **리더보드** | 발언 수 · 활동일 · 채널 수, 기간·채널 필터 |

### 에이전트 계정

Claude / Codex **연결** 버튼 → 브라우저 로그인만. 계정마다 격리된 홈
(`data/agents/<agent>/<id>/`)에서 벤더 CLI 자체의 로그인을 돌리므로
**자격증명은 이 PC를 떠나지 않는다.** `tests/test_launcher.py` 가 이 격리를 검증한다.

Claude 계정을 연결하면 **이 프로젝트의 MCP가 자동으로 붙는다.** 사용자가 할 일이 없다.

### MCP 연결

**기본 제공은 주소를 입력하지 않는다.** 버튼 하나로 붙고, 인증이 필요하면 CLI가 브라우저를 띄운다.

`Discord 수집기(자동)` · `Notion` · `Figma` · `Linear` · `Sentry` · `GitHub`

목록에 없는 서버는 **온디맨드** 칸에서 이름과 주소를 직접 넣는다
(`http://127.0.0.1:3845/mcp` 같은 로컬 주소도 된다).

> 카탈로그 URL이 바뀌면 [app/launcher.py](app/launcher.py) 의 `MCP_CATALOG` 한 줄만 고치면 된다.
> Codex는 `config.toml` 직접 편집 방식이라 콘솔에서 MCP를 다루지 않는다.

### 서비스 아이콘

카탈로그 항목은 각 서비스 파비콘으로 표시된다. **서버가 한 번 받아
`data/icons/` 에 캐시**하고 `/icon/<key>` 로 내려준다 — 사용자 브라우저가 외부로
요청을 내보내지 않고, 한 번 받으면 오프라인에서도 뜬다. 못 받으면 글자 마크로 떨어진다.

> 어떤 사이트는 없는 파비콘 경로에 **SPA 껍데기 HTML 을 200 으로** 돌려준다.
> 그대로 저장하면 브라우저가 조용히 거부하므로 내용을 검증하고 다음 후보로 넘어간다.

### 마스코트 Hebi

사이드바의 Hebi 는 상태에 따라 반응한다 (대기 / 작업 중 / 완료 / 봇 꺼짐).
기본은 내장 SVG 이고, **이미지를 넣으면 그걸 쓴다.**

```
data/mascot/idle.png  working.png  happy.png  sleep.png   ← 로컬 전용 (gitignore)
app/mascot/...                                             ← 저장소에 넣어 배포할 때
hebi.png 하나만 넣으면 모든 상태에 그걸 쓴다
```

`.png .webp .gif .jpg .svg` 를 받는다. 내장 SVG 는 실존 버추얼 유튜버의 캐릭터
디자인이 아니라 이름(へび=뱀)만 빌린 오리지널이다. 공식 에셋을 쓰려면 위 폴더에
넣으면 된다.

### 연동하지 않으면 못 쓴다

MCP 툴 4개는 전부 앞단에서 연동을 확인한다. 이 PC에 등록된 CLI 계정이
디스코드에 연동돼 있지 않으면 **조회 자체가 거부된다.** 남의 계정으로는 못 쓴다.
페어링 코드는 1회용이고 10분 만료다.
**같은 에이전트에 같은 계정은 한 번만 등록된다.** 이미 등록돼 있으면 새로 만들지 않고
알려준다 (기존 등록이 만료됐을 때만 새 로그인으로 교체한다). Claude 와 Codex 에
같은 이메일을 쓰는 건 서로 다른 것이라 허용한다.
**한 번 연동하면 다시 할 필요 없다** — 에이전트 계정은 `data/accounts.json`,
연동 정보는 `data/session.json` 에 남아 콘솔을 다시 열어도 그대로 잡힌다.
콘솔은 서버 상태를 2.5초마다 확인해 연동·채널·새 메시지·봇 기동을 **실시간으로 반영**한다
(탭이 숨겨져 있으면 쉬고, 다시 보이면 즉시 따라잡는다).

## 슬래시 커맨드 — 5개만 남겼다

디스코드 안에서 반드시 닿아야 하는 것들뿐이다. 나머지는 전부 콘솔에 있다.

| 커맨드 | 하는 일 |
|---|---|
| `/시작` | 내 콘솔 링크 + 연동 코드 (서버 관리 권한도 같이 실린다) |
| `/상태` | 수집 채널·건수·최근 수집 시각 |
| `/리더보드` | 상위 5명 + 콘솔 링크 |
| `/수집중단` · `/수집재개` | 내 메시지 제외 / 허용 (콘솔에도 있다) |

**지정한 채널만** 수집한다. 서버 전체를 읽지 않는다.

## Claude Code에서 정리

`.mcp.json` 이 등록돼 있어 이 폴더에서 Claude Code를 열면 툴이 붙는다.
(콘솔에서 Claude 계정을 연결했다면 그쪽에도 자동으로 붙어 있다.)

```
8월 27일 아이디어 채널 정리해줘          → daily-report 스킬
8월 20일부터 26일까지 정리해줘            → 날짜 범위
지난주 대화에서 사업 아이디어 뽑아줘       → idea-extract 스킬
```

| MCP 툴 | |
|---|---|
| `list_channels()` | 수집 채널과 건수 |
| `recent_days(channel, days)` | 날짜별 메시지 수 — 어느 날을 정리할지 고를 때 |
| `get_conversation(channel, date, until="")` | 하루치 또는 **날짜 범위** 원문 |
| `search_messages(query, channel, since, until, limit)` | 부분일치 검색 |

**노션 쓰기는 자동으로 하지 않는다.** 초안을 보여주고 확인받은 뒤에 기록한다.

## 파일

```
run.py              진입점 — 봇 + 콘솔을 한 프로세스로
start.bat           로컬 실행. 창을 닫으면 둘 다 종료
Dockerfile          컨테이너 배포용
deploy/start.sh     DisHost(Pterodactyl) 시작 — cloudflared + 앱을 같이 띄운다
app/
  bot.py            수집 봇 + 콘솔용 브리지. LLM 없음
  db.py             스키마 + 공용 쿼리. UTC 저장, KST 조회
  mcp_server.py     읽기 전용 MCP 서버 + 연동 게이트
  launcher.py       콘솔 API · 페어링 서버 (127.0.0.1:8787)
  console.html      콘솔 UI (탭 4개). 요청마다 읽으므로 고치고 새로고침만 하면 된다
                    디자인 토큰은 orca 와 동일 (shadcn/ui neutral)
  remote.py         로컬/원격 판단과 조회. launcher 와 mcp_server 가 같이 쓴다
  digest.py         일일 결산 본문 생성. 모델 선택(Claude/Codex), 키 없으면 통계로 강등
tests/              test_db · test_mcp · test_launcher · test_digest
.mcp.json           Claude Code MCP 등록 (uv run 이라 경로 무관)
data/               SQLite · 등록된 계정 (gitignore됨)
docs/               기획 문서 (로컬 전용, gitignore됨)
```

## 환경 변수

| | 기본값 | |
|---|---|---|
| `DISCORD_TOKEN` | — | 필수 |
| `LAUNCHER_PORT` | `8787` | 콘솔 포트 |
| `LAUNCHER_URL` | `http://127.0.0.1:8787` | 봇이 안내하는 콘솔 주소 |
| `SERVER_URL` | 자기 자신 | 비우면 서버 모드, 넣으면 클라이언트 모드 |
| `PUBLIC_SERVER` | 없음 | `1` 이면 루프백 무토큰 예외를 끈다. **터널·호스팅이면 필수** |
| `TUNNEL_TOKEN` | 없음 | cloudflared 고정 주소용 ([DEPLOY.md](DEPLOY.md)) |
| `CLI_TIMEOUT` | `600` | CLI 한 번 호출의 제한 시간(초) |
| `DIGEST_MODEL` | `claude-opus-5` | 콘솔 설정이 우선. 콘솔을 안 쓸 때의 기본값 |
| `COLLECTOR_DB` · `COLLECTOR_ACCOUNTS` | `data/` 아래 | 테스트에서 갈아끼운다 |

## 설계 메모

- **봇은 멍청하게, 두뇌는 에이전트에.** 요약·클러스터링·아이디어 추출은 전부 스킬이다.
- **UTC 저장 / KST 조회.** 팀이 KST로 말하므로 `2026-08-27` 은 KST 하루를 뜻한다.
  콘솔의 날짜 두 칸은 범위로 읽고, 끝 칸이 비면 오늘까지다.
- **스레드 메시지는 부모 채널 소속으로 저장한다.** 하루치 요약에 스레드 논의가 같이 딸려와야 한다.
- **삭제·수집중단은 raw 이벤트로 잡는다.** 캐시에 없는 옛 메시지도 확실히 가려진다.
- **콘솔 → 봇은 `run_coroutine_threadsafe` 브리지.** 콘솔은 별도 스레드라 봇 루프에
  코루틴을 넘겨야 한다.
- **CLI 호출은 전부 스레드풀로.** `claude mcp list` 하나가 이벤트 루프를 몇 초씩 막는다.
- **MCP 커넥션은 호출마다 연다.** MCP가 툴을 워커 스레드에서 돌리는데 SQLite 커넥션은
  스레드에 묶이기 때문.
- **리더보드 집계는 파이썬에서 KST로 접는다.** `created_at` 의 마이크로초까지 SQLite `date()`
  가 안전하게 못 읽는다.
- **콘솔 디자인은 orca 를 따랐다.** `app/console.html` 상단 토큰은 orca 리소스에서 그대로
  가져온 shadcn/ui neutral 값이다 (primary `#171717`/`#e5e5e5`, radius `.625rem`,
  사이드바 `239px`). 라이트/다크 둘 다 지원한다. 로고와 파비콘은 봇 아바타를 쓴다.
- **로컬이냐 원격이냐는 `remote.py` 한 곳에서만 판단한다.** 조회 응답 모양도 거기서
  통일한다 — 로컬 SQLite 행과 서버 JSON 이 다르면 원격 모드가 조용히 깨진다.
- **`Mount` 는 경로 prefix 를 안 벗긴다.** `root_path` 만 채우므로 `/c/<토큰>` 에서
  토큰을 직접 잘라내야 한다. 안 그러면 토큰 자리에 `c` 가 잡혀 전부 401 이 된다.
- **LLM 은 API 키가 아니라 연동된 CLI 로 부른다.** 그 계정의 구독으로 돌아가므로
  키를 받아 보관할 일이 없다. 대신 **서버에 CLI 가 깔려 있어야** 한다 —
  파이썬만 주는 호스팅에서는 결산이 통계로 강등된다.
- **CLI 에 넘기는 대화는 신뢰할 수 없는 입력이다.** 도구를 전부 막고 빈 임시
  디렉터리에서 돌린다. `test_digest.py` 가 이 두 가지를 고정한다.
- **저장소는 SQLite 로 충분하다.** 보존 90일 · 하루 500건이면 파일이 14MB 를 안 넘는다.
  Postgres(Supabase 등)가 필요해지는 건 호스팅이 영구 디스크를 안 줄 때뿐이다.
- **결산 게시 전에 `digest_last` 를 먼저 찍는다.** 실패해도 같은 날 여러 번 올리지 않는다.
- **`digest.build` 는 실행자로 보낸다.** LLM 호출이 블로킹이라 봇 루프를 막는다.
- **페어링 요청은 stdlib `urllib`.** 호출 한 곳 때문에 HTTP 클라이언트를 의존성에 넣지 않는다.
