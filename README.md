# Abstraction Bot — 디스코드 대화 수집 → 요약 → 노션

봇이 대화를 모아 SQLite에 쌓고, MCP로 에이전트에 노출하고, 에이전트가 정리해서 노션에 쓴다.
**운영은 거의 다 웹 콘솔에서 한다. 각 사용자는 자기 CLI 에이전트를 연동해야 쓸 수 있다.**

## 구조

```
[디스코드] ──메시지──▶ [수집 봇] ──▶ SQLite ──▶ [MCP 서버] ──▶ [내 Claude Code] ──▶ [노션]
                          │                        ▲
                       브리지                  연동 확인 (미연동이면 거부)
                          ▼                        │
                    [세팅 콘솔]  ── 페어링 ─────────┘
              대화 · 수집 · 연결 · 리더보드
```

봇에는 LLM 호출도 노션 클라이언트도 없다. 요약 프롬프트를 고쳐도 봇을 재배포하지 않는다.

## 설치 · 실행

```bash
uv sync
```

`.env` 를 만든다 (`.env.example` 복사 후 `DISCORD_TOKEN` 채우기). `.env` 는 커밋되지 않는다.

**`start.bat` 더블클릭.** 창 하나에서 수집 봇과 세팅 콘솔이 같이 뜨고,
**그 창을 닫으면 둘 다 종료된다.**

> `MESSAGE CONTENT INTENT` 가 꺼지면 봇이 뜨지 않고 안내 메시지를 낸다.
> 개발자 포털 > Bot > Privileged Gateway Intents 에서 켠다.

## 세팅 콘솔 — 여기서 거의 다 한다

디스코드에서 **`/시작`** 을 치면 본인 전용 콘솔 링크가 온다 (연동 코드 자동 첨부).

| 탭 | 하는 일 |
|---|---|
| **대화** | 채팅형 뷰어. 채널·날짜 범위 선택, 빠른 칩(오늘/어제/7일/30일), 본문 검색(하이라이트), 각 메시지에서 디스코드 원문으로 점프 |
| **수집** | 서버의 채널을 켜고 끄기, 과거 대화 가져오기(날짜 범위 또는 최근 N일, 진행률 표시), 내 수집 거부 — *서버 관리 권한자만 보인다* |
| **연결** | 에이전트 계정 · 디스코드 연동 · MCP |
| **리더보드** | 발언 수 · 활동일 · 채널 수, 기간·채널 필터 |

### 에이전트 계정

Claude / Codex **연결** 버튼 → 브라우저 로그인만. 계정마다 격리된 홈
(`data/agents/<agent>/<id>/`)에서 벤더 CLI 자체의 로그인을 돌리므로
**자격증명은 이 PC를 떠나지 않는다.** `tests/test_launcher.py` 가 이 격리를 검증한다.

Claude 계정을 연결하면 **이 프로젝트의 MCP가 자동으로 붙는다.** 사용자가 할 일이 없다.

### MCP 연결

**기본 제공은 주소를 입력하지 않는다.** 버튼 하나로 붙고, 인증이 필요하면 CLI가 브라우저를 띄운다.

`Discord 수집기(자동)` · `Notion` · `Figma` · `Linear` · `Sentry` · `GitHub`

목록에 없는 서버는 **온디맨드** 칸에서 이름과 주소를 직접 넣는다
(`http://127.0.0.1:3845/mcp` 같은 로컬 주소도 된다).

> 카탈로그 URL이 바뀌면 [app/launcher.py](app/launcher.py) 의 `MCP_CATALOG` 한 줄만 고치면 된다.
> Codex는 `config.toml` 직접 편집 방식이라 콘솔에서 MCP를 다루지 않는다.

### 마스코트 Hebi

사이드바의 Hebi 는 상태에 따라 반응한다 (대기 / 작업 중 / 완료 / 봇 꺼짐).
기본은 내장 SVG 이고, **이미지를 넣으면 그걸 쓴다.**

```
data/mascot/idle.png  working.png  happy.png  sleep.png   ← 로컬 전용 (gitignore)
app/mascot/...                                             ← 저장소에 넣어 배포할 때
hebi.png 하나만 넣으면 모든 상태에 그걸 쓴다
```

`.png .webp .gif .jpg .svg` 를 받는다. 내장 SVG 는 실존 버추얼 유튜버의 캐릭터
디자인이 아니라 이름(へび=뱀)만 빌린 오리지널이다. 공식 에셋을 쓰려면 위 폴더에
넣으면 된다.

### 연동하지 않으면 못 쓴다

MCP 툴 4개는 전부 앞단에서 연동을 확인한다. 이 PC에 등록된 CLI 계정이
디스코드에 연동돼 있지 않으면 **조회 자체가 거부된다.** 남의 계정으로는 못 쓴다.
페어링 코드는 1회용이고 10분 만료다.
**한 번 연동하면 다시 할 필요 없다** — 에이전트 계정은 `data/accounts.json`,
연동 정보는 `data/session.json` 에 남아 콘솔을 다시 열어도 그대로 잡힌다.
콘솔은 서버 상태를 2.5초마다 확인해 연동·채널·새 메시지·봇 기동을 **실시간으로 반영**한다
(탭이 숨겨져 있으면 쉬고, 다시 보이면 즉시 따라잡는다).

## 슬래시 커맨드 — 5개만 남겼다

디스코드 안에서 반드시 닿아야 하는 것들뿐이다. 나머지는 전부 콘솔에 있다.

| 커맨드 | 하는 일 |
|---|---|
| `/시작` | 내 콘솔 링크 + 연동 코드 (서버 관리 권한도 같이 실린다) |
| `/상태` | 수집 채널·건수·최근 수집 시각 |
| `/리더보드` | 상위 5명 + 콘솔 링크 |
| `/수집중단` · `/수집재개` | 내 메시지 제외 / 허용 (콘솔에도 있다) |

**지정한 채널만** 수집한다. 서버 전체를 읽지 않는다.

## Claude Code에서 정리

`.mcp.json` 이 등록돼 있어 이 폴더에서 Claude Code를 열면 툴이 붙는다.
(콘솔에서 Claude 계정을 연결했다면 그쪽에도 자동으로 붙어 있다.)

```
8월 27일 아이디어 채널 정리해줘          → daily-report 스킬
8월 20일부터 26일까지 정리해줘            → 날짜 범위
지난주 대화에서 사업 아이디어 뽑아줘       → idea-extract 스킬
```

| MCP 툴 | |
|---|---|
| `list_channels()` | 수집 채널과 건수 |
| `recent_days(channel, days)` | 날짜별 메시지 수 — 어느 날을 정리할지 고를 때 |
| `get_conversation(channel, date, until="")` | 하루치 또는 **날짜 범위** 원문 |
| `search_messages(query, channel, since, until, limit)` | 부분일치 검색 |

**노션 쓰기는 자동으로 하지 않는다.** 초안을 보여주고 확인받은 뒤에 기록한다.

## 파일

```
run.py              진입점 — 봇 + 콘솔을 한 프로세스로
start.bat           실행. 창을 닫으면 둘 다 종료
app/
  bot.py            수집 봇 + 콘솔용 브리지. LLM 없음
  db.py             스키마 + 공용 쿼리. UTC 저장, KST 조회
  mcp_server.py     읽기 전용 MCP 서버 + 연동 게이트
  launcher.py       콘솔 API · 페어링 서버 (127.0.0.1:8787)
  console.html      콘솔 UI (탭 4개). 요청마다 읽으므로 고치고 새로고침만 하면 된다
                    디자인 토큰은 orca 와 동일 (shadcn/ui neutral)
tests/              test_db · test_mcp · test_launcher
.claude/skills/     daily-report · idea-extract
.mcp.json           Claude Code MCP 등록 (uv run 이라 경로 무관)
data/               SQLite · 등록된 계정 (gitignore됨)
docs/               기획 문서 (로컬 전용, gitignore됨)
```

| | 기본값 | |
|---|---|---|

## 설계 메모

- **봇은 멍청하게, 두뇌는 에이전트에.** 요약·클러스터링·아이디어 추출은 전부 스킬이다.
- **UTC 저장 / KST 조회.** 팀이 KST로 말하므로 `2026-08-27` 은 KST 하루를 뜻한다.
  콘솔의 날짜 두 칸은 범위로 읽고, 끝 칸이 비면 오늘까지다.
- **스레드 메시지는 부모 채널 소속으로 저장한다.** 하루치 요약에 스레드 논의가 같이 딸려와야 한다.
- **삭제·수집중단은 raw 이벤트로 잡는다.** 캐시에 없는 옛 메시지도 확실히 가려진다.
- **콘솔 → 봇은 `run_coroutine_threadsafe` 브리지.** 콘솔은 별도 스레드라 봇 루프에
  코루틴을 넘겨야 한다.
- **CLI 호출은 전부 스레드풀로.** `claude mcp list` 하나가 이벤트 루프를 몇 초씩 막는다.
- **MCP 커넥션은 호출마다 연다.** MCP가 툴을 워커 스레드에서 돌리는데 SQLite 커넥션은
  스레드에 묶이기 때문.
- **리더보드 집계는 파이썬에서 KST로 접는다.** `created_at` 의 마이크로초까지 SQLite `date()`
  가 안전하게 못 읽는다.
- **콘솔 디자인은 orca 를 따랐다.** `app/console.html` 상단 토큰은 orca 리소스에서 그대로
  가져온 shadcn/ui neutral 값이다 (primary `#171717`/`#e5e5e5`, radius `.625rem`,
  사이드바 `239px`). 라이트/다크 둘 다 지원한다. 로고와 파비콘은 봇 아바타를 쓴다.
- **페어링 요청은 stdlib `urllib`.** 호출 한 곳 때문에 HTTP 클라이언트를 의존성에 넣지 않는다.
